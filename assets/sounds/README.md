# Sonidos

Esta carpeta contiene los archivos de audio utilizados en la aplicación.

## Archivo de sonido requerido

- **success.mp3**: Sonido de éxito que se reproduce cuando un repartidor completa una entrega.
  - Duración recomendada: 1-2 segundos
  - Formato: MP3
  - Tamaño recomendado: < 100KB
  - Ejemplo: Sonido similar al de Duolingo cuando terminas una lección

## Cómo agregar el archivo

1. Obtén o crea un archivo de sonido de éxito (success.mp3)
2. Colócalo en esta carpeta: `assets/sounds/success.mp3`
3. La aplicación lo detectará automáticamente

## Recursos para obtener sonidos

- [Freesound.org](https://freesound.org/) - Sonidos gratuitos con licencia Creative Commons
- [Zapsplat.com](https://www.zapsplat.com/) - Efectos de sonido gratuitos
- [Mixkit.co](https://mixkit.co/free-sound-effects/) - Sonidos gratuitos para uso comercial

Busca términos como: "success", "achievement", "level up", "notification success"
